# Tiptap 官方 UI 迁移

状态：2026-10-14 用户确认并授权实施。

## 已确认范围

- 删除现有自研工具栏，按需组合免费官方 Tiptap UI Components。
- 接受缺少免费官方组件的工具入口减少；文字颜色面板是用户授权的唯一自建例外。
- UI 配色跟随现有 ExUI light/dark/system 主题。正文已存颜色不随切换改写。
- 保留文档 schema、转换、安全门禁、上传和 Mention 生命周期。
- 保留 `toolbar`、`renderToolbar` 与只读接口；背景与定位由业务层包装。

## 实现边界

官方源码从 `ueberdosis/tiptap-ui-components` 的 MIT 公开仓库按依赖闭包引入，记录 revision 和 LICENSE。不新增付费组件、Cloud 或另一套 Radix 依赖；原语适配 ExUI，图标使用官方原始 SVG，样式使用限定作用域的 CSS Modules。用户后续明确豁免工具栏的 Lucide 规则。官方按钮和 hook 继续负责编辑命令与状态。

保留撤销重做、标题、列表、引用、代码块、文字 marks、对齐、高亮、链接与本地图片上传。移除字号、独立文字背景色、图片 URL、自定义折叠/提示块及其他没有免费官方入口的工具。已有内容仍可读取、查看与交换。

链接输入遵守 RHF/Zod；弹层在文档替换、只读或卸载后失效。颜色预设提交实际十六进制值，禁止将主题 CSS 变量存入文档。本地图片按钮接入既有取消、代际与位置映射，不新增上传临时节点。

## 验收

真实 Editor 的自动测试覆盖官方命令、链接校验、文字颜色/高亮的转换保真、文档替换后的弹层失效和上传取消。浏览器覆盖明暗主题、键盘、移动端与放大布局。自动检查、浏览器证明和部署分别报告。
