# Tiptap 工具栏外观与交互设计

日期：2026-10-14。模块：`tiptap-support`。状态：已由用户确认的 `.notes/tiptap-support/specs/2026-10-14-official-ui-design.md` 取代；本文件仅保留旧自研方案的设计背景。

## 决策摘要

重做共享 Tiptap 工具栏的布局、选择控件和状态反馈。以 ex-hub 的紧凑分组、图标下拉与圆形色块弹层为交互参考，使用现有 ExUI 公共组件、Lucide 和 CSS Modules 实现。工具栏根容器及分组透明，业务层负责背景、Glass、外层边框、阴影和定位。

本设计补充 `.notes/tiptap-support/specs/2026-10-14-tiptap-support-design.md` 的工具栏部分；文档 schema、内容转换、异步上传、Mention 与查看器职责继续遵循现有实现及 `.ai/knowledge/components/tiptap-content-boundaries.md`。模块根目录继续使用 `.notes/tiptap-support/`，本设计获批准后向 `.notes/tiptap-support/rfcs/` 交接，不直接开始实现。

## 现状与参考证据

- 当前 `packages/components/src/tiptap/toolbar/TiptapToolbar.tsx` 使用原生段落样式选择器。字号、文字颜色、背景色、高亮和清除操作混在一个长菜单里，颜色以编号展示。
- 当前工具栏样式位于 `packages/components/src/tiptap/TiptapEditor.module.scss`，依靠 flex 换行适配窄宽度；命令可用状态、菜单选中状态及 Tooltip 尚不完整。
- 参考工程 ex-hub 的 `src/Hub/TipTap/Editor/index.tsx` 按撤销重做、节点、文字格式和对齐组织工具；标题及列表菜单根据编辑器状态展示图标和选择项。
- 参考工程 `src/Hub/TipTap/Editor/Marks/Highlight/` 使用圆形色块与清除入口；`src/Hub/TipTap/Editor/Marks/Link/` 提供紧凑链接输入弹层。
- 参考工程 `src/Hub/TipTap/Editor/index.scss` 为工具组设置半透明背景、backdrop blur 和阴影。旧工具区使用 ResizeObserver，在自身宽度不超过 1050px 时隐藏 Marks 和 TextAlign；右键菜单保留这些操作。
- 用户明确要求背景由业务层包装。新版工具栏只沿用参考工程的交互与分组，不携带其背景材质。
- 当前 `TiptapEditorProps` 已有 `toolbar?: boolean`；原生 Editor 与 TiptapLifecycle 属于共享组件内部能力，不向业务层公开。

## 方案取舍

采用旧版交互参考与 ExUI 控件组合。现有项目已具备这些控件，且自定义 Admonition、上传生命周期与内容门禁需要保留。

直接引入整套官方 Tiptap UI 将增加另一套 primitives、样式和源码维护范围，不能自动补齐本项目的全部工具。官方免费组件可用于核对命令状态、键盘和选区处理；本轮不引入官方 UI 源码，也不依赖付费组件。继续仅调整现有 CSS 无法解决原生选择器和混合长菜单，因此不采用。

官方接入和许可依据为 [UI Components 总览](https://tiptap.dev/docs/ui-components/getting-started/overview)、[免费高亮面板](https://tiptap.dev/docs/ui-components/components/color-highlight-popover) 与 [Start 方案文字颜色面板](https://tiptap.dev/docs/ui-components/components/color-text-popover)，于 2026-10-14 核对。许可按组件判断，不能将某个组件的付费要求扩大到全部 UI。

## 组件与业务边界

`TiptapToolbar` 负责命令控件、分组、激活与禁用状态、选区保持、菜单以及按容器宽度收纳工具。根容器保留 `role="toolbar"` 和可读名称。容器不绘制背景、Glass、外层边框或阴影，也不自行吸顶或绝对定位。

按钮的 hover、pressed、disabled 和 focus-visible 反馈，以及下拉、Popover 和 Tooltip 的标准表面样式继续由 ExUI 提供；这些是控件自身的可读性与交互反馈，不属于业务层背景。

在 `TiptapEditorProps` 增加可选 `renderToolbar?: (toolbar: ReactNode) => ReactNode`。默认直接渲染工具栏；业务层可将收到的完整工具栏节点包装在自己的背景或定位容器中。回调不暴露 Editor、命令或上传生命周期，也不改变工具栏内部逻辑。`toolbar={false}`、只读模式或实例未就绪时不调用回调、不挂载工具栏；外层包装不能绕过该规则。

业务包装必须保留传入的工具栏节点。编辑器外框与内容样式不属于本轮背景调整范围。共享包不新增 GlassSeed，也不导入全局样式。

## 布局与功能

宽度充足时按以下顺序显示分组，使用间距和细分隔线区分，不给分组添加背景：

| 分组 | 控件与行为 |
| --- | --- |
| 历史 | 撤销、重做，按当前历史状态禁用。 |
| 段落 | 正文及 H1–H4 下拉，显示当前样式和选中项；引用、代码块、列表为图标入口，列表菜单包含无序、有序和任务类型及缩进操作。 |
| 文字 | 粗体、斜体、下划线、删除线、行内代码；独立字号下拉与清除文字格式入口。 |
| 颜色 | 文字颜色、文字背景、高亮各有独立图标入口和色块弹层。 |
| 插入 | 链接、图片地址、配置回调时可用的本地图片，以及折叠块、提示容器、分隔线、硬换行的插入菜单。 |
| 对齐 | 左、居中、右、两端对齐，显示当前激活状态。 |

保留当前所有命令，包括解除折叠和解除提示容器。恢复示例、主题切换、只读切换、JSON / Markdown 面板和业务保存按钮继续由调用页面负责。

所有图标按钮统一尺寸和间距，提供中文可读名称；Tooltip 展示操作名和实际支持的快捷键。默认按钮尺寸使用 rem，触屏保证至少 44px 的交互区域。选择项提供选中标记，格式按钮表达按下状态；混合选区不假装具有统一格式。

## 字号与颜色

字号采用 ExUI 自定义下拉，默认项清除显式字号。预设为 12、14、16、18、20、24、32、48，分别写入当前受支持的 rem 值；显示数字时明确它是以 16px 基准换算的字号标签。导入的其他合法字号显示对应数值，混合字号显示“混合”。本轮不增加任意字号输入框。

颜色面板以可见圆形色块表示选项，每项有颜色名称、Tooltip、可读名称及当前选中标记；清除操作单独展示。文字色沿用现有默认文本、链接、成功、警告、危险语义色；背景与高亮沿用当前四种非默认语义色。默认文字色使用清除文字颜色，背景及高亮提供“无”。

触发按钮显示对应类别及当前颜色提示。当前文档颜色不在预设中时仍展示实际色值，不将其错误标成某个预设。颜色从 ExUI token 解析为当前校验允许的实际十六进制值再提交，不将 CSS 变量写入文档。主题变化更新控件与预设展示，不改写文档已有显式颜色。

## 宽度适配

观察工具栏实际容器宽度，包括业务层包装后的可用宽度，不直接复用旧版 1050px 阈值。工具优先级固定，从右侧低频分组开始收纳：对齐、插入、颜色、次要文字工具与字号、次要段落工具。收纳以完整逻辑工具或分组为单位，原位置和更多菜单只保留一个可交互入口。

窄宽度优先保留撤销重做、段落样式、粗体、斜体、下划线和“更多”。更多菜单按原分组组织所有收纳工具，字号与颜色面板继续可用。极窄容器中核心工具允许换行，页面不出现横向滚动。

不依赖右键菜单提供被收纳的唯一入口，本轮不新增右键菜单。菜单已打开或焦点位于将收纳的工具时延迟重排，关闭菜单或离开工具后再应用最新宽度，避免 resize 导致丢失输入与焦点。观察器测量稳定后不循环触发重排。

## 选区、错误与可访问性

鼠标操作工具栏不丢失原编辑选区。键盘用户可以进入工具栏、通过左右方向键及 Home/End 移动焦点、打开菜单、选择项目、用 Escape 关闭，并通过 Tab 离开。弹层表单允许正常输入与焦点导航；取消不改变文档，应用成功后恢复编辑器焦点。

工具状态从当前 Editor 订阅，不通过重复回传整篇文档重建编辑器。使用实际 command 可用性与激活状态；已销毁实例不执行命令。非法 URL、图片属性或文档预算拒绝时保留表单内容和当前文档，通过现有固定文案与字段错误展示，不能把 command 返回 true 当作事务已应用的唯一证据。

链接与图片表单沿用 React Hook Form、Zod 和 ExUI Field。上传仍经过现有生命周期；不因工具栏重排重新发起上传，也不绕过内容校验。弹层使用 portal，业务 Glass 或定位容器不能改变弹层坐标与裁切行为。

## 验证与验收

- 组件测试使用真实 Tiptap 实例验证段落、字号、颜色、清除、状态订阅及选区保持；覆盖业务包装、无工具栏、只读、卸载和异常拒绝。
- 真实浏览器验证下拉与色块外观、明暗主题、键盘进出、滚动后弹层定位、触屏宽度、200% 缩放及容器 resize；查看完整与收纳布局均可访问全部命令。
- 确认工具栏根容器和分组无背景、Glass、外框及阴影；验证业务层包装可控制背景而不改变工具功能。
- 更新 `tests/browser/tiptap-preview.mjs` 对工具栏的相关断言；运行所属组件测试、Web 与组件类型检查，以及必要的 Web 构建验证。自动检查与真实浏览器结果分别报告。
- JSON / Markdown 语义、只读行为、图片上传及现有内容门禁保持回归覆盖。工具栏变化不要求 API 或数据库变更。

## 交付范围

实现位置集中在 `packages/components/src/tiptap/toolbar/`，按字号、颜色、节点菜单、状态和布局拆分；公开 props 位于 `packages/components/src/tiptap/types.ts`，编辑器挂载入口位于 `packages/components/src/tiptap/TiptapEditor.tsx`。组件与浏览器测试随行为更新。

本轮不扩展文档节点、不增加表格、字体家族、上下标或查找替换，不迁移旧项目依赖、Markdown 实现或自定义扩展。设计文档保留在本模块目录；批准后的 RFC 明确实施切分与验证命令。本次 brainstorming 到 RFC 交接结束。
