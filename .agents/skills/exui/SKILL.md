# ExUI

ExUI provides reusable components, shared Tokens, forms, Glass surfaces, and application notifications. Use this skill in consuming applications. Package-source maintenance follows the repository's own instructions.

**Components** are basic UI elements, such as Button, Input, and Dialog. **Blocks** are reusable interface sections assembled from these basic components. The docs category previously labeled ExUI is labeled Blocks; its existing `exui/` URLs remain stable.

## Authority

1. The consuming application's installed `@exre/exui` version, public exports and declarations.
2. The reviewed ExUI notes at the start of each [component-family reference](references/components.md), the contracts in [references/exui](references/exui/setup.md), and these rules.
3. The upstream pattern material following those ExUI notes, for selection and composition ideas.

Family pages start with ExUI-native or ExUI-adapted notes where the installed API, appearance or behavior differs. Read those before adapting the upstream material, which preserves guidance for both Base UI and Radix. Its `c-*` files are example descriptions, not exported ExUI components or complete TSX sources. The maintained bilingual site pages live in the repository's `packages/docs/content/`; component source pages follow `content/<locale>/components/<family>.mdx`, with ExUI-specific guidance under `exui/` and design-system guides under `tokens/` and `getting-started/`. Verify props against the installed package; do not install upstream registry items to consume ExUI.

## Work loop

1. **Choose** the component family in the [component directory](#component-directory); for a screen, read [compose](rules/compose.md) and state its regions, density and data states.
2. **Read** [setup](references/exui/setup.md), the relevant rules below, and the selected component/example documents. Resolve exact symbol names through the [public export inventory](references/generated/component-exports.md).
3. **Adapt** data and documented props while keeping the component's own geometry, focus behavior and motion. Import components only through `@exre/exui`.
4. **Check** [quality](rules/quality.md) and [anti-patterns](rules/anti-patterns.md). Report actual validation and any unverified behavior.

Complete the loop only when every component used has a verified public import and every data region has the states the task needs.
