# ExWebsite 项目协作

ExWebsite 由 Exre Delivery Squad 承接，入口为 Exre Lead。团队可服务多个项目；Agent 描述与提示词只定义角色职责、能力、产出和协作边界，不绑定具体项目、技术栈或仓库路径。项目定位、资源、角色分工与专属审批规则写在 Monica 项目提示词中，工程实现规则由当前仓库及适用子目录的 AGENTS.md 和相关知识提供，不跨项目继承。

本文只记录 ExWebsite 的项目协作约定。日常工作选择满足验收的最短流程，只在重要架构、重大功能问题或重大 UI 设计确认时请求用户审查。

## 本项目分工

| 角色 | 职责 |
| --- | --- |
| Lead | 协调范围、负责人、依赖、审批和验证证据，推动验收。 |
| Architect | 形成符合已接受架构和契约的功能设计，不写生产实现。 |
| Interaction Designer | 调研同类设计、制定规划、制作交互 HTML 并交付 Frontend。 |
| Engineer | Server、Contract、Client、数据库开发与 Debug，负责授权内 Git 写入。 |
| Frontend | 正式页面及共享组件开发、UI Debug 和实现优化。 |
| Reviewer | 独立审查产物，返回问题及证据，由原作者修复。 |
| Tester | 独立验证功能、接口及真实浏览器行为，按需增加测试。 |

## 任务路径

明确的小功能、修复和文档由所属负责人直接处理，按风险执行独立审查和验证。不要将每个任务拆成完整 PRD、设计、测试、文档流水线。Architect 仅参与有实质设计需要的功能。

Architect 使用 `brainstorming --handoff --module=<模块名>` 自主读取相关 `.ai/`、比较可行方案并输出完整设计，交 Reviewer 独立审查，并有效 @Lead 组织审批。只有交互设计、交互 Demo、架构设计和重大变化需要用户审批；已有获批范围内的开发、修复、代码复审、测试和日常交接自主推进，团队放行不得记为用户确认。不要为已可实施的方案例行追加重复 RFC/PRD。

普通返工、可恢复环境问题和实现选择自主处理，不因轮次增加重复请求用户审查。确实缺少不可推断的输入时，只提出具体缺失信息。Git、外部系统与数据操作沿用任务已有授权，不通过团队规则扩大权限。

## 交互设计到开发

1. Interaction Designer 查找同类产品及优秀设计，记录来源、检索日期、可核对的受欢迎依据、借鉴点及适用理由；无法核实受欢迎程度时说明依据局限，不冒称热门。
2. 制定用户流程、信息层级、布局、关键状态和响应式规划，与 Architect 核对业务和契约约束，遵循既有 ExUI 体系。
3. 制作可实际操作的 HTML Demo，覆盖主要流程及相关空态、加载、错误、成功状态，完成浏览器验证并提供打开方式。模拟数据须明确标识，不接入真实写入或更改生产代码。
4. 重大新页面、主流程、布局或广泛交互变化，由 Lead 提交 Demo 给用户实际体验并确认具体版本；截图或文字设计不能替代。未答复不算确认，重大变化重新打开受影响门禁。
5. 确认后交付 Frontend：参考与规划、Demo 版本、审批来源、组件和 ExUI 对应关系、交互状态、响应式要求及可验证的验收清单。Frontend 实现，Interaction Designer 核对设计一致性，Reviewer 和 Tester 独立检查。

已有获批行为的缺陷修复及局部样式优化可直接开发；不得借此绕过重大设计确认。设计、Demo 与交付材料保留在 `.notes/<module>/`，稳定知识按 `.ai/README.md` 的归属规则维护。

## 协调与证据

一个规范任务记录保存范围、验收条件、负责人、候选版本、审批来源、验证证据、阻塞和下一步。仅在独立可交付或确有并行需要时拆子任务。

内部协作留在 Monica；每次交接在当前线程写明候选、结论和下一步，用当前 roster 的有效 mention 链接只 @一位接手者。开发或修复完成交独立 Reviewer；复审或测试失败交原作者；复审通过交适用 Tester，无需独立测试则交 Engineer；测试通过交 Engineer 交付，再交 Lead 验收。派发前核对活动任务，已有人接手不重复触发，不同时 mention 和 dispatch，不因交接改派或关闭父 Issue。不得只写“建议下一步”、假定 Lead 会看到或等待用户手工 @。Lead 派发后注册实际任务终态的一次性唤醒兜底，恢复时先去重；审批则等待用户实际答复。

作者不能自审；评审和必需验证覆盖同一候选。内容改变后刷新受影响证据，保留仍然有效的无关结果。报告 PASS、FAIL、BLOCKED、NOT_EXECUTED；必需证据缺失阻止适用验收。自动测试、真实浏览器和部署验收分别记录。

共享本地目录、Git 索引和运行服务的修改串行；保留用户和其他任务的改动。Engineer 负责授权内 Git 写入，遵循 CONTRIBUTING.md 与 code-commiter。测试和 runtime 仍遵循相关模块规则，不连接开发库作为自动测试替代，不隐式迁移或 reset。本阶段不部署上线。

## 知识入口

开工先按 `.ai/README.md` 查找模块知识；架构及 Contract 见 `.ai/architectures/overview.md`，数据模型见 `.ai/databases/data-model.md`，Form、通知及主题见 `.ai/rules/` 与 `.ai/knowledge/web/exui-integration-traps.md`。测试遵循现有 TESTING.md（存在时）或仓库测试约定；启动检查单与运行命令见 `README.md`，资源边界见 `.ai/architectures/runtime/runtime-boundaries.md`。
