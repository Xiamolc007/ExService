# `mock-server` 模块：认证生命周期

本文件说明认证 operation 如何落到状态服务与固定本地 SQLite。HTTP 形状仍以 `api/openapi.yaml` 为唯一事实来源；这里记录控制流和状态边界。表的职责与关系见 [数据库模型](../../databases/data-model.md)。

_最后更新：2026-09-24_

## 组合与依赖

`server.ts` 打开固定 Mock 数据库、检查认证和资料结构、管理员社区身份组与验证码 HMAC 密钥，然后构造 `AuthService` 和 `ProfileService` 注入 `createApp()`。SSO CLI 使用相同的结构前置检查。handler 只调用注入的服务，不自行打开数据库，也不复制 Contract schema。

```text
Contract operation
  → fastify-openapi-glue 校验与规范化
  → handlers/auth.ts
  → AuthService
  → auth_* SQLite 表
```

受保护 operation 先由 Glue 的 Bearer security handler 解析本站 token，并把内部会话身份挂到当前请求。退出、SSO 会话确认和异步头像处理在真正写入前会再次检查会话，避免认证检查之后发生撤销或到期。头像文件在资料表引用更新之前写入固定本地目录；数据库写入或会话复核失败时删除新文件，替换或移除头像后只清理不再被引用的旧文件。图片只通过当前数据库引用提供，文件目录不作为独立的公开资源目录。

头像 URL 默认使用本机 Mock 地址。通过代理或 HTTPS 隧道访问时，启动 Mock Server 前设置 `MOCK_PUBLIC_AVATAR_BASE_URL` 为浏览器可访问且以 `/api/avatars` 结尾的完整 HTTP(S) 地址；该值来自受控环境配置，不从请求 `Host` 头拼接。

图片验证码取图 operation 当前由 handler 直接返回无缓存的占位 PNG、随机标识和展示用到期时间；它不进入 `AuthService` 或数据库。认证请求的可选 `captcha` 对象当前不参与验证，不能把这个占位接口当作人机防护。未来启用真实校验时需要为挑战与消耗行为增加服务端状态和验证规则。

## 三类状态

### 注册尝试

注册资料先进入待验证状态。验证码摘要与注册尝试绑定；重发替换摘要、重置错误次数并保留同邮箱冷却。账号只在验证码验证事务中创建，唯一索引和事务共同决定邮箱竞争结果。用户名允许重复，其含义见 [CONTEXT.md](../../CONTEXT.md)。

验证成功的事务只创建正式账号并更新注册状态，不写社区组成员关系；新用户因此具有普通身份。显式增量迁移移除既有 `general` 成员关系并建立 `admin` 组；已有的其他显式组关系保留。启动检查组表与 `admin` 组是否存在，并拒绝尚有旧 `general` 组的数据库；请求路径不会隐式授予管理员身份。组的业务含义见 [数据库模型](../../databases/data-model.md)。

完成、取消或保留期到期后会清除用户名、密码哈希和验证码摘要等不再需要的材料。完成状态在验证码原有效期内保留有限幂等重试能力：正确验证码可重复得到同一成功结果，错误验证码仍累计，不能仅凭注册标识获知完成状态。

Contract 0.3.0 移除注册请求中的 `qq`，旧客户端携带该字段会被 `additionalProperties: false` 拒绝。前后端须同步更新，不提供兼容字段。`0002_remove-registration-qq.sql` 增量移除旧表的 QQ 唯一索引与列，保留账号、会话、SSO 和待验证记录；应用前运行显式 `pnpm db:migrate`，不重置数据库。

### 本站会话

普通登录创建固定 7 天期限的不透明 token；响应交付原文，数据库只保存 SHA-256 摘要。读取当前用户、退出登录与已有会话完成 SSO 都通过同一会话校验路径，不因使用而续期。

### SSO 请求

SSO 请求只能由显式本地 CLI 创建。HTTP 接收端可以检查请求，并通过密码或仍有效的本站会话把它绑定到用户。密码路径不调用普通登录，不创建 `auth_sessions`；相同用户重复确认幂等，不同用户不能覆盖已经完成的请求。

## 密码与验证码资源边界

密码使用异步 scrypt。单个服务实例最多同时执行两个密码工作，等待队列最多 16 个；超出时返回带 `Retry-After` 的固定 `AUTH_BUSY` 错误。未知邮箱仍走合法 dummy hash，避免明显跳过密码计算。

验证码只在事务提交后通过注入的投递适配器交付；本地适配器把邮箱与验证码输出到 Mock Server 终端。验证码 HMAC 密钥缺失或格式错误时服务拒绝启动，不生成临时密钥，也不重置数据库。

## 清理

认证请求入口会限批惰性清理到期状态：注册尝试先清除敏感材料并保留短期墓碑，会话到期或撤销后删除，SSO 请求在到期后继续保留一天供 CLI 检查。清理只操作认证表，不迁移、重置或删除数据库文件。
