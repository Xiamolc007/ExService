# ExWebsite

本仓库以单份 HTTP Contract 驱动 Web、生成式 Client 和唯一 Fastify Server。Server 使用独立的 PostgreSQL `exre` 数据库；目前仍处开发阶段。

_最后更新：2026-10-01_

## Language

**Contract（API Contract）**:
前端与 Server 共同遵守的唯一 HTTP API 事实来源。任何一方都不得在 Contract 之外新增路径、字段或错误格式；实现只能从 Contract 派生行为或类型。
_Avoid_: 接口文档、Swagger 文件、示例 API

**operation**:
Contract 中一个具体的「HTTP 方法 + 路径」行为单元。它是 Contract 与实现之间的最小交付单位。
_Avoid_: 接口、路由、endpoint 定义

**operationId**:
把一个 operation 绑定到其实现者（handler）的稳定标识。Service handler 是否被注册，以及覆盖检查是否通过，都以它为准；文件位置不参与解析。
_Avoid_: handler 名、路由名、函数名

**Server**:
本仓库唯一的 Fastify 服务，按 Contract 注册路由并实现行为。当前单实例开发拓扑不意味着已具备公网生产部署条件。
_Avoid_: Mock Server、临时后端、PHP 接管服务

**开发数据库**:
独立的 PostgreSQL `exre` 数据库，由环境变量明确指定；不与 `outline` 共用数据库。自动测试使用独立容器和隔离 schema。
_Avoid_: Mock SQLite、生产数据库、共享测试库

**健康检查**:
Server 自身可用性的最小信号。它表示进程已完成监听前置检查，不表示所有业务流程已经验收。
_Avoid_: 存活探针、业务就绪检查、状态接口

**envelope（错误 envelope）**:
所有失败响应的统一外壳。Contract 只约束它的外壳形状；具体的错误码取值属于实现侧的约定。
_Avoid_: 错误对象、错误详情、error 结构

**migration**:
对 PostgreSQL 应用结构的可执行变更单元。它只能由显式命令应用，服务启动不会生成或应用它。
_Avoid_: 建表脚本、schema 变更、SQL 文件

**baseline migration**:
从空 `exre` 数据库建立当前有效业务结构的首条 PostgreSQL migration；不回放旧 SQLite 历史。
_Avoid_: SQLite 基线、历史数据导入

**受控重置**:
开发专用命令：显式确认 `exre` 后，核验回环地址、连接身份和对象归属，清理本应用结构并重新应用基线；不删除头像目录，也不触及其他数据库。
_Avoid_: 清库、重置环境、删除数据库

**共享 Client**:
前端发起 HTTP 请求的唯一通道，由 Contract 生成的类型支撑。它不定义 endpoint，只承载调用。
_Avoid_: API 封装、请求库、SDK wrapper

**API base URL**:
前端请求前缀。开发环境缺省 `/api`，Vite 将请求代理到唯一 Server。
_Avoid_: 接口域名、服务地址、代理地址

**破坏性 Contract 变更**:
会使既有调用方失效的 Contract 修改（例如删除或重命名 operation、收紧必填字段、改变响应类型）。当前没有版本策略或兼容层，因此这类变更必须单独评审。
_Avoid_: 不兼容改动、大改动、breaking

**Draft-07 兼容子集**:
Contract 中 schema 允许使用的 JSON Schema 关键字范围。它由运行时校验器的语义决定，而不是由 OpenAPI 版本号决定。
_Avoid_: JSON Schema 子集、受限 schema、简化 schema

**加入申请**:
申请人提交加入资料后、等待人工审核的记录。申请与正式账号独立，审核通过也不意味着已创建账号或邮件已送达。
_Avoid_: 临时账号、注册会话

**邀请资格**:
获批申请在邀请期限内可以验证邮箱并完善账号的资格。只读资格检查帮助选择下一步，不证明邮箱归属，也不能授权建号。
_Avoid_: 登录资格、账号权限、邮箱认证结果

**完善凭证**:
邀请验证码验证成功后签发的短期授权，只允许创建绑定申请的账号及有限成功重试。它不属于本站会话，不授予本人资料或 SSO 访问权。
_Avoid_: 登录 token、注册会话、SSO token

**投递尝试**:
一次邀请验证码邮件的交付记录。投递结果与已提交的审核事实独立；失败后可以重发，不能据投递失败推断申请仍待审核。
_Avoid_: 审核结果、邀请资格

**用户名（显示名称）**:
注册界面中的用户名沿用 `nickname` Contract 字段，允许重复，不作为登录标识；账号仍通过邮箱登录。旧文案称为昵称。
_Avoid_: 唯一用户名、用户名登录

**本人资料 snapshot**:
已验证本站会话读取到的当前账号资料，包含仅本人可见的登录邮箱；它不作为公开用户资料响应。
_Avoid_: 公开资料、会话缓存

**社区身份组**:
本站账号可被明确授予的社区成员分组，以稳定 `code` 标识。它不代表游戏角色或 FiveM 权限；当前尚无站内权限判断入口。
_Avoid_: 游戏权限组、角色权限

**普通身份**:
正式账号没有显式社区身份组成员关系时的默认身份；未登录者不因此成为普通用户。
_Avoid_: `general` 成员关系、匿名用户身份

**管理员组（`admin`）**:
只通过受信任的管理流程显式授予的社区身份组；注册不会自动加入。当前没有管理员初始化或权限判断入口。
_Avoid_: 注册默认权限、游戏管理员权限

**本站会话**:
普通登录成功后由 Server 签发、浏览器通过 Bearer 使用的 7 天固定期限会话。原始 token 只交付给浏览器，数据库只保存摘要；它与 SSO 完成结果是两类状态。
_Avoid_: 登录信息、用户缓存、SSO token

**SSO 请求**:
由本地显式 CLI 创建、等待浏览器确认某个账号的短期请求。接收页只能检查或完成它；完成不会签发本站会话，当前也没有生产发起方或轮询协议。
_Avoid_: SSO 会话、回调 token、外部登录凭据

## 文档服务集成

以下术语描述本地文档服务集成的业务含义。服务边界与控制流见 `.ai/architectures/docs-integration/integration-boundaries.md`；具体 HTTP 形状见 `api/openapi.yaml`。

**网站服务（ExWebsite）**:
承载网站业务的服务，与负责文档业务的 Outline 保持独立。
_Avoid_: 文档服务、Outline 后端

**文档服务（Outline）**:
承载完整文档阅读、编辑与协作能力的服务；对外访问位于网站同域的 `/docs` 路径下，浏览器地址在文档访问过程中保留该前缀。
_Avoid_: 仅公开阅读页、跳转到文档子域名的入口

**统一登录**:
ExWebsite 是统一账号及身份来源，负责注册、登录和账号管理；Outline 通过 Hydra OIDC 关联该身份，不提供独立注册或登录表单。已有有效本站会话的用户进入文档服务时无须再输入密码；Outline 会话仍须单独建立和持续核验。
_Avoid_: 把本地 CLI SSO 当成 OIDC、共享数据库、自动取得全部文档权限

**首次文档接入**:
已登录 Website 的用户首次进入文档服务时，自动建立关联的 Outline 用户，默认可阅读和评论有权访问的文档，但不可新建或编辑文档，无需另行注册或等待邀请。
_Avoid_: 匿名访问自动建号、默认获得编辑或管理权限

**公开文档集**:
以整个文档集为公开单位，其中已发布文档及后续新发布文档允许匿名阅读和搜索引擎收录，草稿不公开；保密内容放入私有文档集。
_Avoid_: 所有文档均公开、必须登录后阅读

**访客文档入口**:
未登录访问 `/docs` 时展示公开文档集目录并提供登录入口，不展示私有文档集的名称或数量。
_Avoid_: 强制登录页、全部文档集目录

**匿名阅读权限**:
未登录访客仅可查看公开内容，不能新建或修改文档，也不具有其他写入权限。
_Avoid_: 匿名编辑、登录后自动获得写权限

**文档授权**:
由 Outline 管理的文档访问与操作权限。普通网站用户登录后默认可阅读和评论有权访问的文档，不自动获得全部私有文档集的访问权；管理员授予指定文档集的编辑权限后，用户才可在其中新建和编辑文档。
_Avoid_: 登录即有编辑权、网站账号自动拥有全部文档权限

**评论权限**:
登录用户可以评论其有权阅读的文档，无需额外获得编辑权限；未登录访客不能评论。评论权限不扩大私有文档的可见范围。
_Avoid_: 只有编辑者可评论、匿名评论、登录后可评论任意私有文档

**文档工作区**:
统一的单个 Outline 工作区，以文档集划分社区或主题，并管理内容及访问权限。
_Avoid_: 每个社区独立工作区、用户自行创建工作区

**文档管理员**:
在 Outline 中单独授予的管理身份，负责文档权限及文档集公开状态；Website 管理员不自动获得该身份。只有文档管理员可以公开或撤销公开文档集，普通文档集编辑者不能改变对外可见性。
_Avoid_: Website 管理员自动映射、编辑权即公开发布权

**首个文档管理员**:
初始化时显式指定的 Website 账号，后续可授予其他用户文档管理权限；不能由第一个访问文档服务的用户自动取得该身份。
_Avoid_: 首次访问自动成为管理员、匿名初始化管理员

**统一退出**:
用户在 Website 或文档页面退出时，结束当前浏览器在两个服务中的会话；退出后仍可匿名阅读公开文档。
_Avoid_: 仅退出当前服务、默认退出所有设备

**账号停用联动**:
Website 账号停用后，Outline 在下一次受保护请求中拒绝该账号，并撤销已有编辑与协作连接；匿名公开阅读仍可使用。
_Avoid_: 仅禁止下次登录、等待文档会话自然过期

**统一用户资料**:
Website 是昵称和头像的唯一修改来源，Outline 跟随更新，不提供独立修改入口。两个服务通过稳定账号 ID 关联身份，修改邮箱不会生成另一个文档用户。
_Avoid_: 两套可独立修改的资料、以可变邮箱作为唯一身份关联

### 首次集成边界

Outline 按最新目标全新初始化，不迁移旧 Outline 用户、文档和权限；此选择不包含重置 ExWebsite 数据。本期交付目标是本地完整联调验收，覆盖子路径访问、匿名阅读、统一身份与退出、文档权限和实时协作，公网部署另行安排。
